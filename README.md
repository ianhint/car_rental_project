# 🚗 Car Rental Booking System

A web-based Car Rental Booking System developed using PHP, MySQL, JavaScript, HTML, CSS, and Bootstrap 5. This system helps customers book rental cars and allows administrators to manage cars, customers, bookings, and payments.

## 🚫 No AJAX

This project uses standard HTML forms with PHP `GET` and `POST` methods.

AJAX and Fetch API are not used. Form submissions are processed by PHP, and the page reloads to display the result.

## ⚙️ Installation & Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Start Apache and MySQL.
3. Clone or download this repository.
4. Place the project folder inside the XAMPP `htdocs` directory.
5. Open phpMyAdmin.
6. Create a database named `car_rental_db`.
7. Import the project's SQL file.
8. Configure the database connection in `config/dbconfig.php`.
9. Open the project in your browser:

   `http://localhost/car_rental/`
